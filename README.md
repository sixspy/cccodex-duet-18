# 对拍

中文名：**对拍** · 前缀 `duet` · 端口 **7800**

## 骨架（新骨，不是闸对/缝包换皮）

**左轨装载 → 右轨装载 → 同键对齐落差 → 单边悬账 → 对拍结论**

| 对比 | 闸对 | 缝包（已弃） | **对本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→在途→成物 | 单流入→在途→成物 | **双轨独立装载→键对齐** |
| 在途态 | 开腿账 | 拼缝账 | **无开腿/拼缝；悬账是对齐后单边** |
| 产物 | 行程账 | 整件账 | **对齐差 + 对拍结论** |
| 旁路名 | 旁路匣 | 旁路匣 | **悬账单（命名与语义都不同）** |

皮：支付渠道回执 vs 核心记账。去皮：**双源键对齐管道**。禁止做成收银 CRUD、报表看板、工单系统。

## 已实现模块（邻题扩展）

### 左缺右留缓冲

仅右轨有键（左缺）时，**入库即择定**且只择定一种形态，右轨命运与处置同事务：

| 形态 | 写入 | 不写 | 右轨命运 | 左到后 | 结论读取 |
| --- | --- | --- | --- | --- | --- |
| 悬账（当场右悬） | 悬账单悬边=右 + 对齐差左缺 | 缓冲表 | `右悬` | 悬账回正 | 悬集 |
| 缓冲（右留缓冲物化包） | 缓冲包待左 + 对齐差左缺 | 悬账 | `右留缓冲` | 缓冲回放 | 包键（读引用不同） |

- 仅右键瞬间即可区分：悬形态**有悬无缓冲**，缓冲形态**有包无悬**。
- 再左同键两边均可对齐，但路径不同：`悬账回正` / `缓冲回放`。
- 处置并发不得悬与缓冲双落：部分唯一索引 + `BEGIN IMMEDIATE` 串行写锁；输家沿用赢家形态。
- 形态策略 `轨规.左缺形态`（`悬账` / `缓冲`），可在「左缺缓冲」页策略卡片切换；切换只影响新处置，已有待左不换形。
- 单边入库后的对齐等待编排：右轨装载内立即处置、左轨装载内立即回放；`POST /api/左缺/编排` 可补跑（回放 → 补处置 → 复核）。

只读处置接口（业务键 / 悬或缓冲键 / valid）：

```bash
GET  /api/左缺/概览            # 策略、卡片、计数、最近对拍
GET  /api/左缺/处置            # 处置列表（valid、有悬行、有缓冲包…）
GET  /api/左缺/处置/{业务键}    # 处置详情（引用表 + 键、悬行、缓冲包、对齐差、valid 原因）
POST /api/左缺/形态            # {"形态":"悬账"|"缓冲"}
POST /api/左缺/编排            # 回放 + 补处置 + 复核
POST /api/左缺/处置/{业务键}    # 立即处置单个仅右键
POST /api/左缺/回放/{业务键}    # 左到后回放
POST /api/左缺/对拍  /  GET /api/左缺/对拍   # 悬账缓冲右轨对拍 + 历史
```

对拍口径：待左悬行数=悬形态待左数、待左包数=缓冲形态待左数；悬与缓冲双落、右命运不符、仅右键未处置均判不通过。
模块只写带标记的悬行（原因 `左缺·当场右悬`）与自身表，基线「跑对齐」重算时保留这些键的留痕，不改基线 happy path 默认口径。
